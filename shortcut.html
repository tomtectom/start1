Wie funktioniert das?

Der iOS-Kurzbefehl liest deine PDFs direkt auf dem iPad aus – ohne Browser-Einschränkungen. Er schickt den Text an Claude und speichert die Flugdaten als flugimport.json. Diese Datei lädst du einfach in der Web-App hoch.

1
Neuen Kurzbefehl erstellen
App: Kurzbefehle

Öffne die Kurzbefehle-App → tippe oben rechts auf + → tippe auf "Neuer Kurzbefehl" oben und nenne ihn "Flüge importieren".

2
Aktion: Dateien holen
Suche nach: Dateien

Suche in der Aktions-Bibliothek nach Dateien und wähle "Dateien" (nicht "Dateien holen").

In der Aktion einschalten: "Mehrere auswählen" → Ein

Tipp: Du siehst oben in der Aktion "Dateien holen" – tippe darauf um die Optionen zu sehen.
3
Aktion: Mit jedem Objekt wiederholen
Suche nach: Wiederholen

Suche nach Wiederholen → wähle "Jedes Objekt wiederholen".

Als Eingabe sollte automatisch "Dateien" aus Schritt 2 erkannt werden.

4
Aktion: Text aus PDF lesen (im Loop)
Suche nach: PDF

Diese Aktion kommt innerhalb der Wiederholen-Schleife.

Suche nach PDF → wähle "Text aus PDF holen".

Die Eingabe ist automatisch das aktuelle Objekt (die aktuelle PDF-Datei im Loop).

Das ist die entscheidende Aktion – iOS liest PDFs nativ aus, ohne Browser-Einschränkung!
5
Aktion: Text zusammenstellen (im Loop)
Suche nach: Text

Suche nach Text → wähle "Text".

Schreibe in das Textfeld folgendes (tippe auf die Variable-Taste {} um Variablen einzufügen):

Analysiere dieses Flugdokument und extrahiere ALLE Flüge. Gib NUR ein JSON-Array zurück, z.B.: [{"date":"2026-09-19","flight":"LH95","from":"MUC","to":"FRA","dep":"09:00","airline":"Lufthansa","class":"Economy"}] Felder: date (YYYY-MM-DD), flight, from (IATA), to (IATA), dep (HH:MM), arr (HH:MM), dur, airline, class. Datum 19SEP26 → 2026-09-19. Airport "Munich/MUC" → "MUC". Kein anderer Text, nur JSON. Dokumentinhalt: [Variable: Ausgegebener Text aus Schritt 4]
Den letzten Teil "[Variable: Ausgegebener Text]" nicht als Text tippen – in Kurzbefehle auf {} → "Ausgegebener Text" tippen!
6
Aktion: Claude API aufrufen (im Loop)
Suche nach: Inhalt von URL

Suche nach Inhalt von URL → wähle "Inhalt von URL holen".

URL https://api.anthropic.com/v1/messages
Methode POST

Tippe auf "Kopfzeilen" und füge diese 3 Einträge hinzu:

x-api-key sk-ant-... (dein API Key)
anthropic-version 2023-06-01
content-type application/json

Tippe auf "Abfragetext" → wähle "JSON" → füge hinzu:

model claude-haiku-4-5-20251001
max_tokens 2048 (als Zahl)
messages Liste → Wörterbuch → role: "user", content: [Text aus Schritt 5]
Tipp: Bei "messages" tippe auf + → Wörterbuch → dann "role" = "user" und "content" = Variable aus Schritt 5 einfügen.
7
Aktion: Antwort extrahieren (im Loop)
Suche nach: Wert für Schlüssel

Füge 2× "Wert für Schlüssel holen" ein:

7a. Schlüssel: content – aus der API-Antwort (Schritt 6)

7b. Danach: "Erstes Objekt" holen (suche nach "Erstes")

7c. Danach: "Wert für Schlüssel": text

→ Das ist jetzt das JSON-Array mit den Flugdaten dieser PDF.

Speichere es in einer Variablen: "In Variable setzen" → Name: "Flug Ergebnis"

8
Aktion: In Datei speichern (nach dem Loop)
Suche nach: In Datei sichern

Diese Aktion kommt außerhalb der Schleife.

Suche nach In Datei sichern.

Eingabe Variable "Flug Ergebnis"
Speicherort Auf meinem iPad → z.B. Flights 2026
Dateiname flugimport.json
Überschreiben Ein
9
Aktion: Mitteilung anzeigen
Suche nach: Mitteilung

Suche nach Mitteilung → Text: "Fertig! Öffne die Web-App und lade flugimport.json hoch."

✅ Shortcut fertig!

Starte den Shortcut → wähle deine PDFs aus dem Ordner "Flights 2026" → warte kurz → öffne die Web-App und lade die gespeicherte flugimport.json hoch.
